# M1 - Docker

## Concepts
- **Image**: read-only template (code + deps + OS layers), built from a Dockerfile.
- **Container**: a running instance of an image; isolated, disposable.
- **Volume**: persistent storage that survives the container. Bind mount = host folder (`-v $(pwd):/app`); named volume = managed by Docker.

## Commands I used
- `docker run -it --rm python:3.9.16-slim` (interactive, auto-remove)
- `docker run --entrypoint=bash ...` (overwrite default endpoint)
- `docker run -v $(pwd):/app ...` (mount current folder)

## Gotchas
- Files written inside a container vanish when it's removed unless they're on a volume.
